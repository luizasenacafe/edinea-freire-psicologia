# Site profissional - Edinéa Freire Psicologia

Site estático reconstruído para publicação no GitHub Pages.

## Estrutura

- `index.html`: conteúdo e estrutura da página
- `styles.css`: identidade visual e responsividade
- `script.js`: estrelas animadas, menu, animações e ampliação dos relatos
- `assets/images`: imagens originais preservadas do site anterior

## Publicação

O projeto não exige compilação. No GitHub Pages, publique a partir da raiz da branch principal.
